# Todo API на Go

Простой REST API для управления задачами (Todo List) с аутентификацией пользователей.  
Проект написан на **Go** с использованием **PostgreSQL** и упакован в **Docker**.

---

# Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/kickez8/todo-api.git
cd todo-api

# 2. Запустить проект одной командой
docker-compose up -d --build
